# Personal Expense Tracker

## 1. Project Description

Personal Expense Tracker is a simple Python-based application used to record, view, search, delete, and manage daily expenses.

The project helps users keep track of their spending and provides a category-wise summary of expenses.

## 2. Objectives

- To record daily expenses.
- To view all recorded expenses.
- To calculate the total expense.
- To search for a particular expense.
- To delete an expense.
- To display category-wise expense summary.
- To store expense data permanently using file handling.
- To apply Python programming concepts in a practical project.

## 3. Features

- Add Expense
- View Expenses
- Calculate Total Expense
- Search Expense
- Delete Expense
- Category-wise Summary
- Automatic date recording
- File-based data storage
- Exception handling for invalid input
